# craftbolt

Craft and reshape bolt text streams with deterministic transforms.

**Site:** https://theworker02.github.io/craftbolt/

## Install / run

```bash
git clone https://github.com/theworker02/craftbolt.git
cd craftbolt
node src/cli.js
node --test
```
